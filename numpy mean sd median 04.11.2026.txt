If a value is at the 25th percentile, it means:

25% of the data is below that value
75% of the data is above it

-> How to find 25th Percentile?

P = (n-1)/100 * 25
P = (5-1)/100 * 25
P = 4/100 * 25
P = 0.04 * 25
P = 1


So for 25th percentile the data is at index 1 which is 20

So for 75th percentile the data is at index 3 which is 40

How to find Outlier?

Interquartile Range
IQR = Q3 − Q1
IQR = q3 - q1 = 40 - 20 = 20

Lower = q1 - 1.5 * IQR = 20 - 1.5 * 20 = 20 - 30 = -10
Higher = q3 + 1.5 * IQR = 40 + 1.5 * 20 = 40 + 30 = 70

for val in data:
if val < Lower or val > Higher:
print("Outlier: ", val)

/
import numpy as np
data = [10, 30, 20, 40, 50]
q1 = np.percentile(data, 25)
q3 = np.percentile(data, 75)
IQR = q3 - q1

Lower = q1 - 1.5 * IQR
Higher = q3 + 1.5 * IQR

for val in data:
    if val < Lower or val > Higher:
        print("Outlier:", val)
    else:
        print("No outlier")
