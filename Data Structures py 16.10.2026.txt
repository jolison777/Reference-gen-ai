Lists (Shopping Lists)
=====

A List is a collection where you can store multiple values (items).
You can change the items later (mutable).
Items are stored in order, and duplicates are allowed.
Used to store Temporary data


mutable  -- modify the things
immutable -- we cannot change

Access      list[index]         fruits[1] → 'banana'

Append      list.append(item)       fruits.append('grape')
Extend      list.extend([item1, item2]) fruits.extend(['kiwi', 'pear'])
Remove      list.remove(item)       fruits.remove('orange')
Sort        list.sort()         fruits.sort()

Tuple (Like PAN Card details)
=====

-> A tuple is like List but we can't change it (immutable)
-> It is also ordered and allows duplicates.
-> It is faster than List.




we cannot midify :
a = ()

Creating a Tuple:
fruits = ("apple", "grape", "orange")


#Tuple maintains the insertion order.
fruits = ("apple", "grape", "orange")
print(fruits)


#After creation, elements cannot be changed.
fruits = ("apple", "grape", "orange")
fruits[0] = "banana"

#Duplicate values are allowed.
fruits = ("apple", "grape", "apple")
print(fruits)




Operation   Syntax          Example Description
Access      tuple[index]        fruits[1] → 'grape'
Count       tuple.count(item)   fruits.count('apple') → 1
Index       tuple.index(item)   fruits.index('orange') → 2
Length      len(tuple)      len(fruits) → 3 
Concatenation   tuple1 + tuple2 fruits + ('kiwi',) → ('apple','grape','orange','kiwi')

Access
------

fruits = ('apple', 'grape', 'orange')

print(fruits[0]) 
print(fruits[-1])
print(fruits[5])

Count
-----
#Returns the number of occurrences of a value.

fruits = ('apple', 'grape', 'orange', 'apple', 'apple')
print(fruits.count('apple'))
print(fruits.count('banana'))

index
-----------

#Returns the position of the first occurrence.

fruits = ("apple", "grape", "orange")

print(fruits.index("orange"))

Length
------
#Returns total number of elements.

print(len(fruits))

Concatenation
-------------
#Combines two tuples.

fruits = ("apple", "grape", "orange")

new_fruits = fruits + ("kiwi",) # The comma tells Python it is a single-element tuple.
print(new_fruits)

Set
===

-> It is an inbuild Data structure which does not allow duplicates.
-> it is unordered
-> It is Mutable
-> Does not support indexing (set[0] is invalid)

union -> It combines all unique elements from both sets.
intersection -> shows matched data between the data sets
minus -> Returns items present in the first set but not in the second set.
