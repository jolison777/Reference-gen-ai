try block will be at start of a code
The except block will handle the error.
The else block will execute code when there is no error.
The finally block lets you execute code, regardless of the result of the try- and except blocks.

| Exception         | Meaning                   | Fix                   |
| ----------------- | ------------------------- | --------------------- |
| NameError         | Variable not defined      | Define variable       |
| TypeError         | Wrong data type operation | Convert type          |
| ValueError        | Invalid value format      | Validate input        |
| IndexError        | Invalid list index        | Check length          |
| KeyError          | Missing dictionary key    | Use `.get()`          |
| ZeroDivisionError | Dividing by zero          | Check before division |
| FileNotFoundError | File missing              | Verify path           |
| AttributeError    | Object has no attribute   | Check method name     |
| ImportError       | Module missing            | Install module        |
| IndentationError  | Wrong indentation         | Fix spacing           |
