------

SELECT *
FROM  EMPLOYEES;

SELECT EMPLOYEE_ID,FIRST_NAME||LAST_NAME
FROM  EMPLOYEES;

SELECT EMPLOYEE_ID,FIRST_NAME||' '||LAST_NAME
FROM  EMPLOYEES;

FROM  EMPLOYEES;

ALIAS NAME (COLUMN)
--------------------

alias is a new column name in the output 
   it wil not change the actual column nmae of the table 
   it will change the column name inly in the output 
   it can be mentiuoned by using of the space or AS
   Alias cannot be used inthe where condition
      Where conditon wil be exeucted first and the output wil be generated 
      after generation of the output , column alias will be fixed in the output
