Dictionary
==========

-> It stores data as key-value pairs.
-> It is Ordered.
-> It is Mutable.
-> Does not allow Duplicate Key.

[1,2,3,4] --list
(1,2,3,4) --tuple
{1,2,3,4} --set
{"key1": "value1", "key2": "value2", "key3": "value3"} --dictonary

employee = {"emp_id": 101, "name": "Asha", "department": "IT", "salary": 65000}

Access
------

# Method 1 - Using square brackets
print(employee["name"])

# Method 2 - Using get() method
print(employee.get("salary"))  

print(employee["age"])

print(employee.get("age"))

Adding and Updating Items
-------------------------

employee["email"] = "asha.it@company.com"
print(employee)

employee["salary"] = 70000
print(employee)

Deleting
---------
del employee['emp_id']
print(employee)

Removing
--------

employee.pop("department")
print(employee)

age = employee.pop("age", 0)
print(age)

employee.popitem()
print(employee)

removed = employee.popitem()
print(removed)

Additional Methods
------------------

print(employee.keys())

print(employee.values())              

print(employee.items())

.items() returns all key–value pairs from the dictionary
Each pair is returned as a tuple
The result is a special object called dict_items

employee.update({"bonus": 5000})
print(employee)

employee.update({"salary": 70000})
print(employee)
